# Финальный чек-лист

## Содержание

- [ ] Основных слайдов не меньше 10
- [ ] Есть минимум 3 интерактива в основной части
- [ ] В конце есть 2–3 вопроса
- [ ] Есть отдельный текст примерно на 15 минут
- [ ] Есть финальный вывод

## Визуалы и шаблон

- [ ] Использован фирменный шаблон университета и сохранена символика
- [ ] Большая часть содержательных слайдов визуальная
- [ ] Нет AI-generated фотографий
- [ ] Все документальные фотографии имеют реальные источники
- [ ] Подписи соответствуют изображениям
- [ ] На обычных слайдах нет мелких серых подписей/ссылок внизу
- [ ] Ни один объект не выходит за границы слайда
- [ ] Нет обрезанного текста и визуальных наложений
- [ ] Нет случайных неровных отступов: элементы одного уровня стоят по общей сетке
- [ ] На слайде нет лишних рамок, карточек и декоративных элементов
- [ ] В среднем сохранено достаточно свободного пространства; слайды не выглядят заполненными «до краёв»
- [ ] На одном слайде не используется лишнее количество акцентных цветов
- [ ] Разнообразие макетов достигается композицией, а не декоративным шумом

## Текст

- [ ] На обычном содержательном слайде примерно 25–45 слов или меньше, если смысл сохраняется
- [ ] Нет длинных абзацев, которые лучше перенести в текст выступления
- [ ] Нет повторения одной мысли в заголовке, подзаголовке и подписи
- [ ] Нет серии шаблонных ИИ-формулировок: «ключевой вывод», «важно отметить», «не просто X, а Y», «в современном мире», «данная концепция позволяет»
- [ ] Термины автора объяснены простым русским языком
- [ ] Текст звучит как речь студента, а не как академическая аннотация или рекламный текст
- [ ] Сценарий выступления не повторяет дословно текст со слайдов

## Источники

- [ ] Источники существуют и проверены
- [ ] Финальная библиография не содержит английских названий, если есть нормальный русский вариант
- [ ] URL не заменяет библиографическое описание
- [ ] Книги и академические публикации имеют приоритет над случайными веб-страницами
