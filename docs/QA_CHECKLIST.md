# Финальный чек-лист

## Содержание

- [ ] Основных слайдов не меньше 10
- [ ] Есть минимум 3 интерактива в основной части
- [ ] Нет отдельного блока контрольных вопросов в конце презентации
- [ ] В конце текста выступления нет вопросов «по презентации», «по рассказу» или блока самопроверки
- [ ] Есть отдельный текст примерно на 15 минут
- [ ] Есть финальный вывод

## Визуалы и шаблон

- [ ] Использован фирменный шаблон университета и сохранена символика
- [ ] Большая часть содержательных слайдов визуальная
- [ ] Для каждого визуала сначала выполнен поиск подходящего реального материала в интернете
- [ ] Реальные фотографии, архивные материалы, карты и музейные изображения имеют приоритет над генерацией
- [ ] ИИ-изображение используется только если подходящего материала в интернете действительно не найдено или доступные материалы непригодны для слайда
- [ ] Если использовано ИИ-изображение, оно высокого качества, без артефактов, визуально соответствует теме и общему стилю презентации
- [ ] На самом слайде нет подписи «ИИ», «AI-generated», «сгенерировано ИИ» или иной технической маркировки происхождения изображения
- [ ] ИИ-изображение не выдаётся за архивную фотографию, исторический документ или доказательство факта
- [ ] Для реальных документальных фотографий сохранены реальные источники
- [ ] Подписи соответствуют изображениям
- [ ] На обычных слайдах нет мелких серых подписей/ссылок внизу, кроме необходимых ссылок/сносок к числовым данным
- [ ] Ни один объект не выходит за границы слайда
- [ ] Нет обрезанного текста и визуальных наложений
- [ ] Нет случайных неровных отступов: элементы одного уровня стоят по общей сетке
- [ ] На слайде нет лишних рамок, карточек и декоративных элементов
- [ ] В среднем сохранено достаточно свободного пространства; слайды не выглядят заполненными «до краёв»
- [ ] На одном слайде не используется лишнее количество акцентных цветов
- [ ] Разнообразие макетов достигается композицией, а не декоративным шумом

## Текст

- [ ] На обычном содержательном слайде примерно 25–45 слов или меньше, если смысл сохраняется
- [ ] Нет длинных абзацев, которые лучше перенести в текст выступления
- [ ] Нет повторения одной мысли в заголовке, подзаголовке и подписи
- [ ] Нет серии шаблонных ИИ-формулировок: «ключевой вывод», «важно отметить», «не просто X, а Y», «в современном мире», «данная концепция позволяет»
- [ ] Термины автора объяснены простым русским языком
- [ ] Текст звучит как речь студента, а не как академическая аннотация или рекламный текст
- [ ] Сценарий выступления не повторяет дословно текст со слайдов
- [ ] На публичных слайдах нет подсказок выступающему, таймингов и служебных комментариев
- [ ] Нижняя часть слайда очищена от лишнего текста, кроме элементов официального шаблона и необходимых ссылок к цифрам

## Источники — требования преподавателя

- [ ] У КАЖДОЙ цифры, статистического значения, процента и количественного показателя есть ссылка на источник
- [ ] Источник действительно содержит указанное числовое значение
- [ ] Если одна ссылка относится к нескольким цифрам, это однозначно видно из оформления
- [ ] Интернет-источники оформлены по схеме: `Автор 1, Автор 2, Название статьи, URL, дата обращения: ДД.ММ.ГГГГ`
- [ ] Авторы перечислены через запятую
- [ ] Названия статей написаны без кавычек
- [ ] Для интернет-источников указан URL
- [ ] Для интернет-источников указана дата обращения
- [ ] Нет голых URL вместо библиографического описания
- [ ] Для книг указаны автор, название, место издания, издательство и год
- [ ] Для научных статей указаны авторы, название, журнал/издание, год, номер/выпуск и страницы, если доступны
- [ ] Источники существуют и проверены
- [ ] Финальная библиография не содержит английских названий, если есть нормальный русский вариант
- [ ] Книги и академические публикации имеют приоритет над случайными веб-страницами
