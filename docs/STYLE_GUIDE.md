# STYLE_GUIDE.md — чистый стиль учебных презентаций

## Общий принцип

Презентация должна выглядеть как аккуратно собранная университетская работа, а не как интерфейс приложения, рекламный лендинг или набор AI-инфографики.

Главная цель — понятность с расстояния и спокойный визуальный ритм.

## Сетка

- Использовать постоянные поля слева и справа.
- Все текстовые блоки одного уровня привязывать к одинаковым вертикалям.
- Если на соседних слайдах используются одинаковые элементы, их положение и размеры должны совпадать.
- Не ставить элементы «примерно» по месту. Любая заметная неровность считается дефектом.

## Плотность

Нормальный содержательный слайд должен иметь свободное пространство.

Ориентир:
- 1 главный визуал + 1 короткий текстовый блок; или
- 2 спокойные колонки; или
- 1 простая схема; или
- 1 вопрос аудитории.

Плохо:
- 5–8 мелких карточек одновременно;
- несколько рамок внутри рамок;
- много разноцветных значков без необходимости;
- подписи в каждом свободном углу;
- декоративные линии, круги и стрелки, не помогающие чтению.

## Разнообразие без перегруза

Использовать 4–6 типов композиции на презентацию:

1. Крупное изображение/карта + короткий комментарий.
2. Две колонки для сравнения.
3. Простая временная линия.
4. Список из 3–4 коротких пунктов с крупной нумерацией.
5. Один вопрос группе с 2–3 вариантами ответа.
6. Один центральный тезис + визуал.

Не нужно делать каждый слайд уникальным. Вариативность нужна только настолько, чтобы презентация не выглядела монотонной.

## Цвет

- Фирменный синий университета — основной акцент.
- На одном слайде допускается ещё один смысловой акцентный цвет.
- Красный использовать для риска/критики, зелёный — для развития/положительного направления, оранжевый — для промежуточного акцента.
- Не использовать сразу 4–5 насыщенных цветов.

## Текст

### На слайде

- Коротко.
- Без длинных абзацев.
- Обычный слайд: примерно 25–45 слов.
- Заголовок не должен повторяться в первой строке текста.
- Если мысль понятна без подзаголовка — подзаголовок не нужен.

### Как убрать «ИИ-текст»

Редактировать фразы до тех пор, пока они не звучат как нормальная речь студента.

Избегать повторяющихся конструкций:
- «важно отметить, что»;
- «ключевой вывод заключается в том, что»;
- «данная концепция позволяет»;
- «в современном мире»;
- «не просто X, а Y»;
- «следует подчеркнуть»;
- «таким образом» в каждом втором абзаце;
- искусственных троек из одинаково построенных тезисов.

Вместо:
> Данная концепция позволяет рассматривать внутреннее развитие как ключевой фактор обеспечения устойчивости государства.

Лучше:
> Для Цымбурского важнее сначала связать и развить собственную территорию.

Вместо:
> Это не просто географическая метафора, а комплексная модель цивилизационного пространства.

Лучше:
> «Остров» здесь — метафора отдельного геополитического пространства.

## Речь на 15 минут

Сценарий должен быть подробнее слайдов, но звучать естественно.

Допустимы живые переходы:
- «Здесь есть спорный момент.»
- «На этом слайде я свёл идею к простому сравнению.»
- «Отсюда следующий вопрос.»
- «Если сказать проще…»

Не нужно превращать текст выступления в научную статью.

## Проверка перед сдачей

Посмотреть всю презентацию в режиме миниатюр и отдельно несколько слайдов в полном размере.

Если в режиме миниатюр всё выглядит как одинаковая сетка карточек — добавить 1–2 других композиции.

Если в полном размере глаза не понимают, куда смотреть сначала — убрать элементы.

Если текст можно сократить на треть без потери смысла — сократить.
