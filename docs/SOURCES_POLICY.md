# Политика источников

Приоритет: книги/монографии → научные статьи → официальные исследования → архивы/музеи → официальная статистика → качественные справочные материалы.

В презентации названия источников отображаются на русском языке. Не писать в финале только URL и не оставлять длинные английские названия. Оригинальные названия, DOI, ISBN и URL сохраняются во внутреннем манифесте.
