# Требования преподавателя к презентациям

## Основные требования

- Не менее 10 основных слайдов.
- По ходу презентации должны быть интерактивы: вопросы к одногруппникам, просьба высказать мнение, короткое голосование или сравнение позиций.
- Не добавлять отдельные контрольные вопросы в конце презентации.
- Не добавлять вопросы по презентации/рассказу в конце сценария выступления.
- Большая часть презентации должна состоять из содержательных визуалов, а не больших массивов текста.
- Использовать фирменный шаблон и символику университета.
- Отдельно готовить текст для устного выступления примерно на 15 минут.

## Источники

- Ко всем цифрам обязательно давать ссылки на источники.
- Это относится к статистике, процентам, количественным показателям и другим проверяемым числовым данным.
- Перед сдачей проверить, что источник действительно подтверждает конкретную цифру.
- Интернет-источник оформлять так: `Автор 1, Автор 2, Название статьи, URL, дата обращения: ДД.ММ.ГГГГ`.
- Авторов указывать через запятую.
- Название статьи писать без кавычек.
- Указывать URL.
- Обязательно указывать дату обращения.
- Не оформлять источник одной ссылкой без автора и названия.
- В библиографии отдавать приоритет книгам, монографиям, научным статьям и официальным материалам.
- Для книг указывать автора, название, место издания, издательство и год.
- Для научных статей по возможности указывать авторов, название, журнал или сборник, год, номер/выпуск и страницы.

### Пример интернет-источника

`Иванов И. И., Петров П. П., Название статьи, https://example.org/article, дата обращения: 17.09.2026`

## Визуальные источники

Использовать реальные фотографии, архивные материалы, музейные изображения, карты и проверяемые схемы. AI-generated изображения не использовать вместо документальных фотографий. Для каждого изображения сохранять страницу происхождения во внутреннем реестре источников.
