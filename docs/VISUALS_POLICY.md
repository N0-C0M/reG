# Политика визуальных материалов

Предпочтительный порядок: документальная фотография; архивная историческая фотография; музейный или библиотечный материал; официальная карта; диаграмма по проверенным данным; собственная объяснительная схема.

Запрещено: генерация фотографий нейросетью, вымышленная реконструкция без маркировки, случайная стоковая картинка, изображение без понятного происхождения, подпись, не подтверждаемая источником.

Не использовать мелкие серые подписи/сноски у нижнего края содержательных слайдов. Полная атрибуция фотографий и ссылки хранятся в реестре источников и при необходимости выводятся на отдельный финальный слайд.
