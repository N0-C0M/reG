# Тема 9 — «Православная цивилизация» А. С. Панарина

Проект учебной презентации по дисциплине «Российская цивилизация в академическом дискурсе».

## Сборка

1. `generate_outputs.py` скачивает реальные фотографии из `image_sources.json`.
2. `build_presentation.py` создаёт `presentation.pptx`.
3. `generate_outputs.py` создаёт `speaker_script.docx` из `speaker_script.md`.
4. `validate_presentation.py` проверяет количество слайдов, минимум 4 изображения и выход объектов за границы.

## Требования

- минимум 10 слайдов;
- реальные интернет-фотографии, не ИИ-генерация;
- интерактивы и финальные вопросы;
- никаких мелких серых подписей/источников внизу обычных слайдов;
- отдельный текст выступления примерно на 15 минут.
