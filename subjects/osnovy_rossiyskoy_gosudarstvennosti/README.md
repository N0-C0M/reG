# Основы российской государственности

Эта папка содержит профиль презентаций **только для предмета «Основы российской государственности» (ОРГ)**.

Именно к этому предмету относятся текущие требования преподавателя и накопленные правила оформления: университетский шаблон и символика, презентация для показа всему классу, отдельный текст выступления примерно на 15 минут, интерактивы по ходу основной части, отсутствие контрольных вопросов в конце, чистая нижняя зона слайда, естественный текст без подсказок докладчику, правила источников и ссылок ко всем цифрам, а также политика использования реальных и ИИ-изображений.

## Важно

Эти правила нельзя автоматически применять к презентациям по другим дисциплинам. Для каждого нового предмета необходимо создать отдельный профиль в `subjects/<subject_id>/` со своими:

- шаблоном презентации;
- требованиями преподавателя;
- структурой и длительностью выступления;
- правилами источников;
- требованиями к интерактивам;
- визуальным стилем;
- QA-чек-листом.

Если для нового предмета профиль ещё не создан, нельзя молча использовать профиль ОРГ. Сначала нужно получить от пользователя шаблон и/или требования преподавателя, после чего создать отдельный профиль.
