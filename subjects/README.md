# Профили предметов

Презентации в этом репозитории разделяются **по учебным предметам**. Требования одного преподавателя, шаблон и визуальные правила одного предмета не должны автоматически переноситься на другой.

## Структура

Каждый предмет получает собственную папку:

`subjects/<subject_id>/`

В ней хранятся профиль требований, описание шаблона, специфические правила преподавателя и при необходимости отдельный QA-чек-лист.

## Текущие профили

- `osnovy_rossiyskoy_gosudarstvennosti/` — Основы российской государственности. Это профиль, к которому относятся все накопленные на данный момент требования пользователя к презентациям.

## Новый предмет

Если пользователь просит презентацию по другому предмету:

1. Не применять автоматически шаблон и специальные требования ОРГ.
2. Определить название предмета.
3. Проверить, существует ли его профиль.
4. Если профиля нет — запросить/использовать предоставленный пользователем шаблон и требования преподавателя.
5. Создать отдельную папку `subjects/<subject_id>/`.
6. Сохранять дальнейшие правки именно в профиле этого предмета.

Общие технические правила, которые действительно подходят всем предметам, в дальнейшем можно вынести в отдельный `common/` профиль. Предметные требования всегда имеют приоритет над общими.
